# lumera

Lumera blockchain node (`lumerad`).

This repository publishes releases only. Development happens in a private repository.

- **Download:** [Releases](https://github.com/LumeraProtocol/lumera/releases). Chain upgrades, the chain registry and cosmovisor download `lumerad` from here.
- **Copied releases:** every earlier release was copied here from the previous repository, with its original files.
- **New releases** carry `SHA256SUMS` (verify with `sha256sum -c SHA256SUMS`). A source tarball will follow once the new release pipeline is in place.
- **Source code archives:** GitHub's "Source code" archives on a release contain only this README.
- **Go:** existing versions of `github.com/LumeraProtocol/lumera` stay available through the Go module proxy. New versions will be published under a new module path.

[RELEASES.md](RELEASES.md) lists every release published here.

Issues are welcome; pull requests are not accepted.
